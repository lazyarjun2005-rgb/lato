# Lato v1.2.1

Lato v1.2.1 packages the completed UI improvements from Phases 1, 2, and 3.

## Highlights

- Polished compact floating dialogs with responsive sizing and complete search/input borders.
- Improved `/model`, `/themes`, `/connect`, custom-provider, session, provider, and permission dialog layouts.
- Improved light-theme readability for main chat text, Markdown, search inputs, and dialogs while preserving dark-theme identity.
- Established the canonical `lato` default theme and `lato-orange` theme identity.
- Preserved `electric-blue` and `opencode` as backward-compatible configuration aliases.
- Retained existing v1.2.0 model discovery, provider configuration, clipboard, and native terminal selection behavior.
